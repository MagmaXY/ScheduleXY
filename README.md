# ScheduleXY

Клиент-серверная экосистема для просмотра расписания занятий лицея, отслеживания замен, ведения заметок и домашних заданий, а также поиска свободных кабинетов.

Проект состоит из двух клиентов:

1. **Web (PWA)** — веб-сервис на React 19, TypeScript, Tailwind CSS и Vite.
2. **Android App** — нативное мобильное приложение на Kotlin и Jetpack Compose с виджетами рабочего стола, фоновыми службами и плитками быстрых настроек (Quick Settings Tile).

---

## 1. Веб-сервис (Web PWA)

Веб-приложение оптимизировано для работы на смартфонах, планшетах и десктопах, поддерживает офлайн-режим через Service Worker и IndexedDB.

### Функциональные возможности

- **Расписание для классов и учителей**: выбор целевого класса или преподавателя, быстрый доступ через избранное.
- **Учет изменений и замен**: наглядная индикация замен, отмен занятий и переносов аудиторий.
- **Режимы отображения**: переключение между обычным списком уроков и режимом «пар» (объединение последовательных уроков одного предмета).
- **Синхронизация по времени (Realtime)**:
  - Автоматическое определение текущего урока и оставшегося времени до конца урока или перемены.
  - Подсветка активного дня и занятия в расписании.
  - Автономный информационный режим `/widget` для киосков и дисплеев.
- **Заметки и домашние задания**:
  - Привязка заметок к выбранному классу/учителю, дате и номеру урока.
  - Фильтры: «Все», «Домашние задания», «Заметки», «Долги».
  - Автоматический перенос домашних заданий на следующий урок при отмене текущего.
  - Быстрое копирование расписания на день с включением домашних заданий и заметок.
- **Календарь и архив**: просмотр учебных недель, общешкольных событий, каникул и архивных расписаний прошедших недель.
- **Свободные кабинеты и учителя**: расчет доступности аудиторий и преподавателей на выбранный день и урок на основе сводного расписания.
- **Персонализация и синхронизация**:
  - Адаптивные темы оформления (Material Design 3, темная/AMOLED тема, кастомные акценты).
  - Фильтрация по языковым подгруппам и технологии.
  - Облачная синхронизация заметок через Яндекс Диск (WebDAV).
  - Экспорт и импорт заметок в формате JSON.
  - Web Push-уведомления через OneSignal.

### Запуск и сборка веб-приложения

```bash
cd web

# Установка зависимостей
npm install

# Запуск dev-сервера (http://localhost:5173)
npm run dev

# Проверка типов и сборка в dist/
npm run build

# Локальный предпросмотр сборки
npm run preview

# Проверка кода линтером
npm run lint
```

## 2. Нативное Android-приложение (Android App)

Нативное приложение построено на стеке **Kotlin + Jetpack Compose + Material 3** и ориентировано на интеграцию с системными сервисами Android (Android 7.0+, API 24+).

### Функциональные возможности

- **Полная функциональность расписания**:
  - Просмотр расписания классов и преподавателей с поддержкой замен и режима пар.
  - Быстрый выбор аудитории/учителя с автодополнением и умным поиском.
  - Переключение дней недели свайпами и верхней панелью.
- **Интеграция с системой**:
  - **Виджет рабочего стола (App Widget)**: интерактивный виджет с текущим расписанием, переключением дней и индикацией времени до звонка (`ScheduleWidgetProvider`).
  - **Шторка уведомлений (Ongoing Status Notification)**: постоянное или настраиваемое уведомление в строке состояния с информацией о текущем уроке, кабинете и таймере перемены/урока (`OngoingStatusNotificationService`).
  - **Плитка быстрых настроек (Quick Settings Tile)**: быстрая плитка в панели уведомлений Android для мгновенного доступа к расписанию (`ScheduleTileService`).
  - **Ярлыки приложений (App Shortcuts)**: контекстные действия на иконке приложения для перехода к расписанию или заметкам.
  - **Динамическая смена иконки**: переключение между стандартной и альтернативной иконкой приложения (включая символику лицея).
- **Фоновые задачи и уведомления**:
  - Фоновая периодическая синхронизация через `WorkManager` (`ScheduleSyncWorker`).
  - Уведомления об обнаружении новых замен в расписании (`ScheduleNotificationManager`).
- **Заметки и долги**:
  - Локальная база заметок с поддержкой Markdown-форматирования текста.
  - Отслеживание статуса выполнения и фиксация долгов по домашним заданиям.
  - Фоновая синхронизация заметок с Яндекс Диском через WebDAV (`YandexDiskSyncService`).
- **Свободные кабинеты**:
  - Офлайн-движок расчета свободных помещений (`FreeAvailabilityEngine`) по предзагруженным расписаниям всех классов.
  - Режим просмотра занятости учителей (защищен паролем администратора).
- **Кастомизация**:
  - Поддержка динамических цветов Material You (Dynamic Color на Android 12+).
  - Темная, светлая и контрастная черная (AMOLED) темы.
  - Выбор подгрупп учащегося (иностранный язык, технология).

### Сборка Android-проекта

Для сборки требуется **JDK 17** и **Android SDK (API 34)**.

```bash
# Сборка debug APK
./gradlew assembleDebug

# Запуск юнит-тестов
./gradlew test

# Проверка линтером Android
./gradlew lint

# Сборка release APK
./gradlew assembleRelease
```

Собранный APK-файл располагается по пути:
`app/build/outputs/apk/debug/app-debug.apk`.

## 3. Руководство пользователя

### Основной сценарий работы

1. **Первоначальный выбор**: при первом открытии веб-версии или мобильного приложения выберите свой класс или фамилию преподавателя. Нажмите значок избранного, чтобы закрепить выбор.
2. **Настройка подгрупп**: перейдите в «Настройки» и укажите вашу группу иностранного языка и технологии, чтобы учитывать уроки подгруппы в ДЗ.
3. **Просмотр замен**: изменения и замены выделяются в карточках уроков цветом и специальными маркерами (перечеркнутый предмет при отмене, указание нового кабинета или замещающего преподавателя).
4. **Работа с заданиями**:
   - Нажмите на любой урок в расписании или перейдите в раздел «Заметки».
   - Добавьте домашнее задание или памятку.
   - Выполненные пункты отмечайте чекбоксом. Невыполненные задания прошедших дней отображаются в фильтре «Долги».
5. **Синхронизация**:
   - Для совместного доступа к заметкам между веб-версией и Android-приложением настройте вход в Яндекс Диск в меню настроек обоих клиентов.
   - Также доступен локальный экспорт/импорт базы заметок через JSON-файл.
6. **Поиск кабинетов**: если нужно найти свободный класс во время «окна», откройте вкладку «Кабинеты», выберите день и номер урока.
