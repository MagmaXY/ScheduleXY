# ScheduleXY — Расписание Инженерного Лицея НГТУ (Android + Виджет 2х2)

Нативное Android-приложение и интерактивный виджет для рабочего стола (2х2 клетки) для просмотра расписания **Инженерного лицея НГТУ**.

Дизайн и UX полностью воспроизводят аутентичный стиль мобильного расписания [`m.schedule.html`](https://lyceum.nstu.ru/rasp/m.schedule.html) (NIKA-Soft: мягкие сине-серые градиенты, чёткая табличная вёрстка, зелёные маркеры времени, выделение кабинетов и групп, без перегруженности), а данные и API берутся с [`https://lyceum.nstu.ru/info/api`](https://lyceum.nstu.ru/info) согласно спецификации OpenAPI.

---

## 📱 Ключевые возможности

### 1. Расписание классов и учителей (в стиле rasp)
- Быстрое переключение между категориями **«Классы»** (10-1, 10-2, 11-1...) и **«Учителя»** (Муль П.Ф., Заковряшина О.В....).
- Кнопка **«★ Это мой класс / В избранное»**: сохраняет предпочтение и автоматически открывает его при запуске приложения и на виджете.
- Удобный селектор дней недели: переключение стрелками `‹` и `›`, плашки дней (Пн..Сб), быстрое возвращение к кнопке **«Сегодня»**.
- Табличные карточки уроков в каноничном стиле:
  - Номер урока (`#AAA`, по центру)
  - Временной диапазон (`#008000`, тёмно-зелёный)
  - Предмет (`#222288`, индиго)
  - Преподаватель (курсив `#226666`) или класс
  - Кабинет (жирный контрастный бейдж `#111111`)
  - Подгруппы (`[гр. 1]`, `[гр. 2]`, синий `#0000FF`)
  - Замены и отмены (`#DD2222`, зачёркивание отменённых уроков)

### 2. Синхронизация с реальным временем (Live Ticker)
- Точная сетка звонков Инженерного лицея НГТУ:
  - 1 урок: 08:15 – 09:00
  - 2 урок: 09:10 – 09:55
  - 3 урок: 10:15 – 11:00
  - 4 урок: 11:15 – 12:00
  - 5 урок: 12:10 – 12:55
  - 6 урок: 13:05 – 13:50
  - 7 урок: 14:00 – 14:40
  - 8 урок: 14:55 – 15:35
- **Живой индикатор статуса** в шапке:
  - *«До начала 1 урока: 25 мин»*
  - *«Идёт 2 урок (до звонка 18 мин)»*
  - *«Перемена до 3 урока (осталось 6 мин)»*
  - *«Уроки на сегодня завершены»*
- **Подсветка текущего урока** в реальном времени с синей рамкой и бейджем «идёт».

### 3. Виджет 2х2 для рабочего стола Android
- Размеры оптимизированы под стандартную сетку рабочего стола **2х2 клетки** (`minWidth="110dp"`, `minHeight="110dp"`).
- **Интерактивность прямо с экрана лаунчера**:
  - Кнопки `‹` и `›` для перелистывания дней недели без необходимости открывать приложение.
  - Кнопка смены цели (`Кл: 10-1` ⇄ `Уч: Муль П.Ф.`).
  - Живой статус звонка («2 урок», «Перемена»).
  - Компактный список уроков (номер, время, предмет, кабинет).
  - Нажатие на виджет запускает приложение прямо на выбранном классе и дне.
- Фоновое обновление через `AppWidgetProvider` и `RemoteViewsService`.

### 4. Вкладка «Календарь»
- Интерактивная сетка месяца в стиле NIKA Calendar:
  - Дни с расписанием подсвечены мягким голубым (`#D7EBFA`).
  - Дни с заменами выделены розовым (`#FFD4D7`).
  - Суббота зелёным (`#009900`), воскресенье красным (`#CC2222`).
  - Сегодняшний день выделен акцентной рамкой (`#8888CC`).
  - Маркеры событий лицея.
- Под календарём — **события лицея** из `/api/events`:
  - Фильтры по категориям: *Учёба*, *Олимпиады*, *Важное*, *Каникулы*, *Экскурсии*, *Контрольные*, *Спорт*.
- Клик по любому дню в календаре мгновенно переключает на расписание этого дня.

### 5. Архив расписания за предыдущие 2 недели
- Поддержка архивных срезов через эндпоинты `/api/schedule/class/:name?week=-1` и `?week=-2` (а также данных из `/api/schedule/archive`).
- Переключатель: **Текущая неделя (0)** / **1 неделя назад (-1)** / **2 недели назад (-2)**.
- Верхний баннер-предупреждение: *«📁 Архив: период XX.XX.2026 – XX.XX.2026»*.

### 6. Свободные кабинеты и свободные учителя
- Поддерживает **оба режима работы**:
  1. **Официальный Admin API** (`/api/schedule/free-rooms` и `/api/schedule/free-teachers`) с передачей заголовка `X-Admin-Password: licey2026` (пароль из OpenAPI документации, настраивается в приложении).
  2. **Встроенный локальный алгоритм расчёта** (`FreeAvailabilityEngine`): если на сервере пароль изменён или доступ закрыт (401), клиент анализирует матрицу занятости всех 39 классов лицея, рассчитывая занятые и свободные кабинеты (1..3 этажи, спецзалы) и преподавателей для любого выбранного слота (Пн..Сб, 1..8 уроки, либо «Прямо сейчас»).

## 🛠 Технологический стек

- **Язык**: Kotlin 2.0
- **UI**: Jetpack Compose + Material 3 (кастомная тема в стилистике NIKA/rasp)
- **Сетевой слой**: Retrofit 2.11, OkHttp 4.12, Gson
- **Асинхронность**: Kotlin Coroutines, StateFlow
- **Кэширование**: Офлайн-кэш `CacheManager` на файловой системе / SharedPreferences
- **Виджет**: Android `AppWidgetProvider`, `RemoteViews`, `RemoteViewsService`
- **Минимальная версия Android**: Android 7.0 (API 24)
- **Целевая версия**: Android 14 (API 34)

## 🚀 Как открыть и собрать в Android Studio

1. Откройте **Android Studio** (Hedgehog, Iguana, Jellyfish или новее).
2. Выберите **File → Open** и укажите папку проекта:
   ```
   C:\Users\user\Documents\GitHub\ScheduleXY
   ```
3. Дождитесь автоматической синхронизации Gradle.
4. Выберите конфигурацию запуска `app` и нажмите **Run ▶** на эмуляторе или физическом устройстве.
